# Instructions – Comment utiliser les modèles de tableaux

Ces modèles sont des **gabarits vides** à remplir après avoir regardé les vidéos assignées.
Ils ne contiennent aucun contenu protégé par le droit d'auteur.

---

## Fichiers disponibles

| Fichier | Format | Vidéo concernée |
|---|---|---|
| `malware_video_template.md` | Markdown | Vidéo malware – ANY.RUN |
| `malware_video_template.csv` | CSV (séparateur `;`) | Vidéo malware – ANY.RUN |
| `cybercriminality_video_template.md` | Markdown | Vidéo cybercriminalité UE – ARTE Europe l'Hebdo |
| `cybercriminality_video_template.csv` | CSV (séparateur `;`) | Vidéo cybercriminalité UE – ARTE Europe l'Hebdo |

---

## Utilisation du fichier CSV (Excel / LibreOffice Calc)

1. Ouvrez Excel ou LibreOffice Calc.
2. Allez dans **Fichier > Ouvrir** et sélectionnez le fichier `.csv`.
3. Dans l'assistant d'importation, choisissez **point-virgule (`;`)** comme séparateur de colonnes et **UTF-8** comme encodage.
4. Remplissez les cellules vides de la colonne **VOTRE RÉPONSE** (ou des colonnes du tableau).
5. Enregistrez au format `.xlsx` ou `.ods` pour conserver la mise en forme.

> **Astuce :** Sous Excel (Windows, région France), vous pouvez aussi renommer le fichier en `.csv` et double-cliquer dessus — Excel utilise automatiquement le point-virgule comme séparateur pour les paramètres régionaux français.

---

## Utilisation du fichier Markdown

1. Ouvrez le fichier `.md` dans un éditeur de texte (VS Code, Obsidian, Typora, etc.).
2. Remplacez chaque `|   |` vide par votre réponse entre les pipes `|`.
3. Vous pouvez aussi copier-coller le tableau directement dans un document Word, Notion, ou GitHub.

## Consignes de remplissage

### Vidéo malware (ANY.RUN)

- **Métadonnées :** titre exact, lien URL, durée, date de mise en ligne.
- **Définition :** nommez précisément le malware, sa famille (ransomware, trojan, spyware, etc.) et les OS ciblés.
- **Propagation :** décrivez comment le malware se propage (pièce jointe, lien, réseau, etc.).
- **Protections :** listez les mesures de protection mentionnées (antivirus, mises à jour, sensibilisation…).
- **Top 13 :** pour chaque malware du classement, indiquez :
  - *Technique / Objectif* : ce que fait le malware (chiffrement, vol de données, botnet…)
  - *Conséquences directes* : impact immédiat sur la victime (perte de données, rançon, espionnage…)
  - *Conséquences indirectes* : impact à plus long terme ou sur des tiers (réputation, pertes financières, infrastructure…)

### Vidéo cybercriminalité (ARTE – Europe l'Hebdo)

- Remplissez **une ligne par attaque ou événement** présenté dans la vidéo.
- Si une information n'est pas mentionnée, écrivez **« non mentionné »** dans la cellule.
- **Colonnes clés :**
  - *Attaque / Événement* : nom ou description courte de l'attaque.
  - *Date* : année ou date précise si connue.
  - *Pays* : pays victime.
  - *Cibles* : entité(s) visée(s) (gouvernement, hôpital, entreprise…).
  - *Auteurs / Nationalité* : groupe, État ou individu responsable.
  - *Motifs* : raison de l'attaque (espionnage, gain financier, idéologie…).
  - *Procédé* : méthode utilisée (ransomware, DDoS, phishing, APT…).
  - *Conséquences directes* : dommages immédiats.
  - *Conséquences indirectes* : répercussions à long terme.
  - *Prévention* : mesures proposées ou appliquées après l'attaque.
